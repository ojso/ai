# 开放缺口

> 本文是开放缺口的**优先级视图与入口**，不是事实源。每条只保留编号、缺口、影响、权威来源与动作；计数、状态和具体数字由来源文档维护。
>
> 适用范围：本目录与 `flask-exts` 的开放缺口、优先级与建议动作
> 更新时间：2026-11-19 08:12:16 +08:00
>
> 优先级口径：P0 优先补齐；P1 公开发布前处理；P2 长期质量。这里的 P0/P1/P2 表示**排期优先级**，不是安全事件等级；安全事件等级以 `security.md` 为准。
>
> 标“主记录在本文”的条目目前没有其他权威文档承载；其余条目只链接来源，不复制其状态或数字。

## 缺口清单

### P0：优先补齐

- **P0-1**
  - 缺口：契约断言与测试设计的语义覆盖尚未逐条核对
  - 影响：`passed` 只证明所列入口通过，不证明断言覆盖契约全部行为
  - 来源：[`requirements.md`](./requirements.md) 第 2.2 节、[`testing.md`](./testing.md) 第 6.2 节
  - 动作：逐条核对 `REQ → 断言内容`，把缺口回填到对应契约的“验收”字段

- **P0-2**
  - 缺口：部分契约未取得批准或执行证据
  - 影响：这些契约的实际通过状态无法判断
  - 来源：[`requirements.md`](./requirements.md) 头部“契约进度”与第 2.2 节
  - 动作：补测试入口映射；由 `check_docs.py` 的仓库交叉检查持续接管

- **P0-3**
  - 缺口：Demo 无自动冒烟
  - 影响：`demo.md` 与实际 demo 可能漂移
  - 来源：[`demo.md`](./demo.md) 第 11.3 节、[`testing.md`](./testing.md) 第 11 节
  - 动作：把现有冒烟片段纳入 CI

- **P0-4**
  - 缺口：CI 未校验本套 Markdown 与 demo 启动
  - 影响：文档链接、锚点和 demo 启动问题不会被现有 CI 捕获
  - 来源：[`testing.md`](./testing.md) 第 11 节、仓库 `.github/workflows/`
  - 动作：新增只读文档检查与 demo 冒烟 job；不重复现有 Sphinx 与 pytest 矩阵

- **P0-5**
  - 缺口：安全项收尾
  - 影响：账号级失败锁定已落地；IP 维度、未知用户名与注册/找回入口限流仍缺
  - 来源：[`security.md`](./security.md) 第 11 节
  - 动作：发布前按 [`security.md`](./security.md) 第 14 节检查，残余项由运维限流或后续实现承接

### P1：公开发布前

- **P1-1**
  - 缺口：自动生成的 API 参考覆盖有限
  - 影响：`docs/api.rst` 只列出部分 Admin/View/Forms API
  - 来源：`flask-exts/docs/api.rst`（**主记录在本文**）
  - 动作：扩展 `automodule` / `autoclass` / `autosummary` 的覆盖范围

- **P1-2**
  - 缺口：兼容矩阵不完整
  - 影响：只记录单一环境的实测结果，未覆盖完整版本组合
  - 来源：[`release.md`](./release.md) 第 3.1 节
  - 动作：补充经验证的 Python / Flask / SQLAlchemy / 数据库 / 浏览器矩阵

- **P1-3**
  - 缺口：安全运营未落地
  - 影响：安全运营的实施状态与响应流程仍待补
  - 来源：[`security.md`](./security.md) 第 13 节
  - 动作：补齐运营流程、责任人与响应安排

- **P1-4**
  - 缺口：部署/运维文档缺失
  - 影响：生产配置、备份、日志、反向代理与迁移指引不足
  - 来源：**主记录在本文**
  - 动作：补充部署与运维指南

- **P1-5**
  - 缺口：性能基线缺失
  - 影响：缺少 p50/p95 与查询数量的实测基线
  - 来源：[`testing.md`](./testing.md) 第 9.7 节
  - 动作：按模板记录 p50/p95 与查询数

### P2：长期质量

- **P2-1**
  - 缺口：ADR 记录不完整
  - 影响：部分架构决策只有模板或分散说明，缺少统一决策记录
  - 来源：[`architecture.md`](./architecture.md) 第 7.1 节
  - 动作：按 `ADR-*` 格式补齐缺失决策

- **P2-2**
  - 缺口：无废弃策略
  - 影响：公开 API 变更缺少保留周期与迁移指引
  - 来源：**主记录在本文**
  - 动作：定义废弃周期、迁移说明与移除条件

- **P2-3**
  - 缺口：文档新鲜度依赖人工
  - 影响：计数、链接、demo 与代码状态可能静默漂移
  - 来源：[`AGENTS.md`](./AGENTS.md) 第 7、10 节、[`check_docs.py`](./check_docs.py)
  - 动作：在 CI 中定期运行只读检查与 demo 重建

- **P2-4**
  - 缺口：无浏览器 E2E
  - 影响：Tom Select、模态框、Flatpickr 等 JS 交互缺少回归覆盖
  - 来源：[`testing.md`](./testing.md) 第 8.4 节
  - 动作：按可选方案引入浏览器 E2E

- **P2-5**
  - 缺口：示例代码块不可执行
  - 影响：文档片段可能与实际 API 脱节
  - 来源：[`testing.md`](./testing.md) 第 14 节
  - 动作：关键片段纳入 doctest 或示例测试
